Other Trivia Plots

Alex Pinard August 18, 2020 Trivia Stats / Visualizations

A preserved collection of early TriviaStats charts exploring player similarity, creator bias, and week-by-week scoring trends.

{% include 'GPTrivia/_blog_post_switcher.html' %}

First, load the trivia_stats.R source file, which contains all functions for generating statistics: 

source("trivia_stats.R")

Player Similarity Table

This chart measures how similar players’ scores are on a given round after adjusting for round difficulty. In the original post, bias measured how well a player does on another player’s rounds, while the similarity table focused on how similarly two players perform across all the rest of the rounds. 

player_similarity_table()

The post also included a 3D representation of that similarity table obtained using Bayesian Principal Components Analysis (BPCA). The locations in 3-space were not meant to be interpreted directly; only proximity mattered. 

plot_3d_similarity_plotly()
Archived widget note. The original similarity, bias, and creator-overlay sections were interactive Plotly widgets. This preserved version keeps the original text and the static figure set that was actually embedded in the post.

Bias Heatmap

Each column represents the scores on one person’s round that week. Higher scores in a cell mean that the player tends to gain more points than other players on that creator’s rounds.

Estimated Score Per Round = Average Score + Round Difficulty + Bias

bias_table_heatmap()
